Janasetu India

Turns citizen requests in Indian languages into ranked development priorities for all 28 states and 8 union territories.

Prototype data. State populations are approximate (Census 2011). Infrastructure indices, poverty rates, internet access, planned spending, costs and the seeded requests are illustrative placeholders, not official figures. Replace them with Census, NITI Aayog SDG India Index, NFHS, PMGSY, Jal Jeevan Mission and BharatNet data before drawing conclusions.

Simulate a citizen message

Write in any Indian language (or English or Hinglish), as if sent by WhatsApp, SMS or a transcribed voice call.

How this works

Claude reads the message in its original language and returns the language, category, state, urgency and an English summary. If Claude isn't reachable (for example when this file is opened outside Claude), a built-in word list covers Hindi, Marathi, Bengali, Assamese, Tamil, Telugu, Kannada, Malayalam, Gujarati, Punjabi, Odia, Urdu and English.

Each category maps to an existing national scheme so recommendations can be routed to a funded programme: PMGSY (roads), Jal Jeevan Mission (water), Ayushman Bharat health centres, Saubhagya/RDSS (power), BharatNet (internet) and Samagra Shiksha (schools).

This version works at state and UT level. Going to all 780+ districts needs district-level datasets; the scoring code doesn't change.
